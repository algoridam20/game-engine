Identity

There is no userId in the JWT. Player id is sub. After create/join, gameId is the room UUID. Chat and play use that game JWT; REST join is the only step that still sends roomId in the body (session JWT has no room yet).

sequenceDiagram
  participant UI as Next.js
  participant API as game-server
  UI->>API: passkey login (session JWT, no gameId)
  UI->>API: POST /api/v1/room/create/init or join/init
  API-->>UI: roomId + game JWT (sub + gameId)
  UI->>API: STOMP CONNECT Bearer game JWT
  UI->>API: SEND /app/v1/chat/join
  API-->>UI: /topic/room/{id} and /topic/room/{id}/player/{sub}
