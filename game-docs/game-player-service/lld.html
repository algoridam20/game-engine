Key call paths

  • Signup finish: ceremony verify → save player → relyingParty.registerCredential → DAO saves passkey → JWT
  • Login finish: ceremony verify → relyingParty.authenticate → load player by WebAuthn user id → JWT
  • Protected API: filter sets PlayerJwtInfo → provider loads entity → service
